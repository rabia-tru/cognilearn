📱 INSTALL NOW:

1. Build & sync:
   npm run build
   npx cap sync android

2. Install on device:
   adb install -r android/app/build/outputs/apk/debug/app-debug.apk
   adb reverse tcp:3000 tcp:3000

3. Start backend:
   npm run dev

4. Launch app:
   adb shell am start -n com.cognilearn.app/.MainActivity
